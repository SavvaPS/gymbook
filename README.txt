GYMBOOK

A personal workout log that runs in the browser and installs like an app.
Your data is saved on your own phone; nothing is sent anywhere.

Install
- iPhone: open the site in Safari, tap Share, then Add to Home Screen.
- Android: open the site in Chrome, tap the menu, then Install app.

Back up now and then (Routines > Backups > Back up now) and keep the file
somewhere safe, as your log only lives on your phone.

Updating the site (for the owner)
1. Replace the files in this folder with the new version.
2. Change VERSION at the top of sw.js so phones pick up the update.
3. In GitHub Desktop: Commit, then Push origin. GitHub Pages republishes
   within a few minutes and the app shows "Reload".
